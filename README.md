# 📋 ASRR SurveyApp - Система анкетирования

Современное десктопное приложение для создания и проведения анкет с условной логикой.

## ✨ Особенности

- 🎯 **Условная логика вопросов (OR)** - вопросы показываются при выполнении любого из условий
- 🖥️ **Кроссплатформенность** - работает на Windows, macOS и Linux
- 🎨 **Современный интерфейс** - красивый и интуитивный дизайн
- 📊 **Админ-панель** - создание и управление анкетами
- 💾 **Локальное хранение** - все данные хранятся на устройстве
- 🔒 **Приватность** - никаких внешних серверов
- 📋 **Копирование вопросов** - быстрое создание похожих вопросов
- 📖 **Встроенная документация** - подробное руководство прямо в приложении
- 🎨 **Логотип ASRR** - профессиональный вид приложения

## 🚀 Быстрый старт

### Установка

1. **Скачайте приложение** для вашей ОС:
   - **Windows**: `SurveyApp.exe`
   - **macOS**: `SurveyApp.app`
   - **Linux**: `SurveyApp`

2. **Запустите приложение** двойным кликом

3. **Настройте анкету**:
   - Нажмите на шестерёнку ⚙️
   - Введите пароль: `admin123`
   - Создайте анкету или импортируйте существующую

### Первое использование

1. **Запустите приложение**
2. **Нажмите кнопку "СТАРТ"** для начала анкетирования
3. **Ответьте на вопросы** - приложение автоматически покажет релевантные вопросы
4. **Завершите анкету** - результаты сохранятся автоматически

## 🛠️ Разработка

### Требования

- Python 3.8+
- PyQt6
- PyInstaller (для сборки)

### Установка зависимостей

```bash
# Создайте виртуальное окружение
python -m venv venv

# Активируйте окружение
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Установите зависимости
pip install PyQt6 PyInstaller Pillow
```

### Запуск в режиме разработки

```bash
python survey_app_pyqt.py
```

### Сборка приложения

```bash
# Создание исполняемого файла для Windows
pyinstaller --onefile --windowed --name "SurveyApp_ASRR" --icon="asrr_logo.ico" --add-data "asrr_logo.ico;." survey_app_pyqt.py
```

**Важно:** Для правильной работы иконки в собранном exe необходимо использовать флаг `--add-data` для включения иконки в сборку.

## 🎛️ Админ-панель

### Доступ к админке

1. Нажмите на шестерёнку ⚙️ в главном окне
2. Введите пароль: `admin123`
3. Управляйте анкетами и настройками

### Функции админки

- **Создание анкет** - добавление вопросов и условий
- **Редактирование вопросов** - изменение текста, типа, вариантов ответов
- **Копирование вопросов** - быстрое создание похожих вопросов одной кнопкой
- **Управление порядком** - перемещение вопросов вверх/вниз
- **Условная логика** - настройка условий показа вопросов
- **Управление ответами** - просмотр и экспорт результатов
- **Настройки** - выбор анкеты по умолчанию, смена пароля
- **Импорт/Экспорт** - перенос данных между системами
- **📖 Документация** - встроенное руководство по созданию анкет

## 📊 Создание анкет

### Типы вопросов

- **Текстовые** - свободный ввод
- **Числовые** - ввод чисел
- **Выбор** - один из вариантов
- **Множественный выбор** - несколько вариантов

### Условная логика

Вопросы могут показываться в зависимости от ответов на предыдущие вопросы. **Важно:** Если у вопроса несколько условий, он покажется при выполнении **ЛЮБОГО** из них (логика OR).

```json
{
  "conditions": [
    {
      "targetId": "question-uuid-id",
      "operator": "greater_than",
      "value": "18"
    },
    {
      "targetId": "another-question-id",
      "operator": "equals",
      "value": "Да"
    }
  ]
}
```

**Примечание:** Условия используют UUID ID вопросов, а не индексы, что позволяет безопасно изменять порядок вопросов без нарушения логики.

### Операторы условий

- `equals` - равно
- `not_equals` - не равно
- `greater_than` - больше
- `greater_or_equal` - больше или равно
- `less_than` - меньше
- `less_or_equal` - меньше или равно
- `contains` - содержит (для множественного выбора или текста)

## 💾 Хранение данных

### Расположение файлов

- **Windows**: `%APPDATA%\SurveyApp\Data\`

- **Linux**: `~/.local/share/SurveyApp/Data/`

### Файлы данных

- `surveys.json` - анкеты
- `responses.json` - ответы пользователей
- `settings.json` - настройки приложения

## 🔧 Настройка

### Изменение пароля админки

Найдите в коде:
```python
if password == "admin123":
```

Замените на свой пароль.

### Изменение иконки

Иконка приложения находится в файле `asrr_logo.ico`. Для замены:
1. Создайте новый ICO файл с размерами 16x16, 32x32, 48x48, 64x64, 128x128, 256x256
2. Замените файл `asrr_logo.ico`
3. При сборке используйте команду с `--add-data "asrr_logo.ico;."` для включения иконки в exe

## 🐛 Устранение неполадок

### Приложение не запускается

1. Проверьте, что у вас установлен Python 3.8+
2. Убедитесь, что все зависимости установлены
3. Проверьте права доступа к папке приложения

### Данные не сохраняются

1. Проверьте права на запись в папку данных
2. Убедитесь, что папка данных существует
3. Проверьте свободное место на диске

### Проблемы с интерфейсом

1. Обновите PyQt6 до последней версии
2. Проверьте настройки масштабирования экрана
3. Перезапустите приложение
